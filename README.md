# 🧮 CodeAlpha Calculator

### A Simple, Responsive & Interactive Calculator

A modern calculator web application developed using **HTML5, CSS3, and JavaScript** as part of the CodeAlpha internship project. It provides a clean user interface and interactive calculator functionality for performing everyday mathematical calculations.

## 🚀 Getting Started

### 1. Clone the Repository

```bash
git clone https://github.com/Snehabelure419/codealpha_calculator.git
```

### 2. Open the Project

```bash
cd codealpha_calculator
```

### 3. Run the Calculator

Open `index.html` in your web browser, or use the Live Server extension in Visual Studio Code.

No additional installation is required for this frontend project.
